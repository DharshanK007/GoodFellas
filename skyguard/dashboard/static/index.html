SkyGuard AI — Scientific Methodology

Physics-Informed Dual-Channel Architecture

SkyGuard AI employs two parallel detection channels. Channel 1 uses a Bidirectional GRU Autoencoder trained on each station's historical baseline to compute a temporal reconstruction error. Channel 2 applies thermodynamic physics constraints: virtual temperature consistency, vapour pressure equilibrium, and refractive index coherence.

Dynamic Advective Coupling Model (DACM)

DACM constructs a wind-weighted directional graph from real-time wind vectors. Edge weight wDACM(i→j) = proximity × cos(θ). Edges with w ≥ 0.3 are classified as dynamic couplings. A genuine meteorological event propagates along these couplings with lag τ = distance / wind_speed.

Multi-Level Reasoning Fusion

Final classification fuses three levels: (L1) temporal anomaly score, (L2) physics violation score, (L3) DACM propagation evidence. Output: NORMAL, STATION_SENSOR_FAULT, GENUINE_METEOROLOGICAL_EVENT, or UNCERTAIN_INSUFFICIENT_EVIDENCE.

Synthetic Benchmark Construction

Six canonical fault scenarios are injected: (1) temperature spike +13.5°C, (2) frozen temperature sensor, (3) gradual pressure drift, (4) humidity saturation fault, (5) coherent propagating cold front, (6) hard negative isolated disturbance. PASS/FAIL determined by comparing model output to expected ground-truth classification.

Dataset Playback vs Live AWS

The system operates in Dataset Playback mode — 14-day hourly observations are fetched from Open-Meteo API and traversed sequentially. Live telemetry ingestion is a planned operational extension.
